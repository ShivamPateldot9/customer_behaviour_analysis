# Customer Purchase Behavior Analysis (SQL)

## 📌 Project Overview
This project analyzes a retail customer transactions dataset using **PostgreSQL** to uncover insights around revenue, customer segmentation, discounts, shipping preferences, subscriptions, and product performance. The goal was to answer real-world business questions that a data analyst is commonly asked to solve — using pure SQL (aggregations, window functions, CTEs, and conditional logic).

## 🛠️ Tools & Skills Used
- **SQL (PostgreSQL)** — aggregate functions, `GROUP BY`, `CASE WHEN`, subqueries, `CTEs`, `ROW_NUMBER()` window function
- **Python** — used for data cleaning / exploration prior to loading into SQL
- **Power BI** — used to visualize key findings from the query outputs *(add a link/screenshot if you built a dashboard)*

## 🗂️ Dataset
A single `customer` table containing transaction-level retail data, including fields such as:
`customer_id`, `gender`, `age_group`, `item_purchased`, `category`, `purchase_amount`, `discount_applied`, `review_rating`, `shipping_type`, `subscription_status`, `previous_purchases`.

## ❓ Business Questions Answered
1. Total revenue generated by male vs. female customers
2. Customers who used a discount but still spent above the average purchase amount
3. Top 5 products by average review rating
4. Average purchase amount: Standard vs. Express shipping
5. Do subscribed customers spend more? (avg spend + total revenue comparison)
6. Top 5 products with the highest discount usage rate
7. Customer segmentation — New / Returning / Loyal (based on purchase history)
8. Top 3 most purchased products within each category (using window functions)
9. Do repeat buyers (5+ previous purchases) show higher subscription rates?
10. Revenue contribution by age group
